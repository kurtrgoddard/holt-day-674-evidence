# Data dictionary (v1.0, evidence frozen 2026-08-26)
Files mirror the companion workbooks; the workbooks (in /replication/source/) remain the canonical calculation layer.
- current_polls.csv — one row per vote-intention observation. basis = respondent denominator as published or derived; core_2026 TRUE enters the 90-day ensemble. normalized_weight = 0.5^(age_days/90) normalized over core rows. Narrative row is a DERIVED decided normalization (rounded all-eligible values / 69); effective n=342 approximate, not pollster-reported. Abacus decided base undisclosed; total n used for variance diagnostics only (optimistic).
- current_indicators.csv — separate question series (satisfaction, handling, approval, favourability, direction). Never pool across measures. Narrative 2026-06 is an online-panel wave; earlier waves telephone (mode break).
- day674_comparison.csv — frozen day-674 rows. retention_ratio = day-674 governing-party poll / its election valid-vote share. margin_drift = final election margin minus day-674 poll margin. Higgs is a minority/pandemic/snap-election sensitivity, not a full-term analogue.
- nowcast_scenarios.csv — deterministic proportional-swing seat conversions of certified 2024 riding votes (three-party normalization). Scenarios, not probabilities.
- firewall.csv — adverse Liberal-PC margin erosion (points) at which each seat flips under the benchmark swing; boundaries 8.237 (majority loss) and 11.370 (PC plurality). Exact values retained; public graphics round to 8.2 / 11.4.
- stress_routes.csv — ecological aggregate mechanisms reaching the same boundaries; not individual voter flows.
- elections_2006_2024.csv — Elections New Brunswick certified results; shares of VALID votes. Boundaries and assembly size changed 2010-2014 and before 2024.
- flagship_chains.csv — five pre-specified flagships across the chain promise - funded action - implementation - service output - resident outcome - public recognition. "NOT YET OBSERVED" is a data status, never converted to a grade.
Poll inclusion rule: independent province-wide NB vote-intention releases with fieldwork midpoint within ~90 days of 2026-08-26; overlapping releases not double-counted. Exclusions retained with core_2026=FALSE.
Software: workbook formulas (see source XLSX); analysis stack Python/pandas/NumPy/lxml. Random seed 20260826 reserved; published analysis deterministic.
- ridings_2024_three_party.csv — certified 2024 three-party riding votes (49 rows; column sums reconcile to 180,806 L / 131,332 PC / 51,558 G). Input to the seat model and firewall.
- code/build.py — executable recomputation harness (Python 3.10+, stdlib only; run: python3 code/build.py from /replication/). Recomputes the recency ensemble, reference interval (DerSimonian–Laird as specified in methodology §4), poll-specific and ensemble seats, majority-loss and PC-plurality boundaries with tie rule (strict-greater winner; bisection tolerance 1e-6), tipping ladder, half-life sensitivity, and hindcast MAEs (definitions printed). Prints PASS/DEVIATION against the stored workbook values; the LOO-drift definition is under-documented in the source and is reported as an open item rather than forced to match.
- current_polls.csv v1.1: other_decided_basis = residual on the published basis (Narrative 11/69 derived; Abacus residual incl. published rounding to 99); undecided_all_respondents kept separate — never mix the denominators.
